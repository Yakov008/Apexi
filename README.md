# Apexi

**Система вместо «по ощущениям».** Apexi — Android-приложение для тех, кто тренируется в зале без тренера: подсказывает, что делать сегодня, быстро записывает подходы, само рассчитывает прогрессию весов, подстраивает нагрузку под самочувствие и объясняет, почему.

> Статус: ранняя разработка (шаг M0 — каркас проекта). Первая рабочая версия 0.1 — в планах.

## Принципы

- **Опора на исследования.** Каждое правило основано на проверяемых источниках (ACSM, NSCA, метаанализы) и помечено уровнем уверенности. См. [правила работы с источниками](docs/stage2-sources-policy.md).
- **Безопасность.** Скрининг-анкета перед выдачей программы; при «красных флагах» — совет обратиться к врачу. Apexi не медицинская услуга и не заменяет консультацию врача.
- **Приватность.** Нет сервера и аккаунтов: все данные хранятся только на телефоне.

## Технологии

- Kotlin, Jetpack Compose, Material 3
- Room (SQLite) — локальная база данных
- Модуль `:domain` на чистом Kotlin с автотестами — правила прогрессии, самочувствия, скрининга
- GitHub Actions — автотесты и сборка APK при каждом изменении
- Android 8.0+ (API 26), целевая версия Android 16 (API 36)

Подробнее — в [документе архитектуры](docs/stage3-architecture.md).

## Сборка

Нужны JDK 17+ (подойдёт встроенная в Android Studio) и Android SDK.

```bash
./gradlew test             # автотесты
./gradlew assembleDebug    # APK: app/build/outputs/apk/debug/
```
