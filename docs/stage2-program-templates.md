# Этап 2, блок 3: шаблоны программ (черновик на утверждение)

Дата: 2026-10-28. Основание: решения №16 (четыре шаблона), №17 (разминка), №18 (список упражнений). Упражнения — из [stage2-exercises-shortlist.md](stage2-exercises-shortlist.md).

## 1. Общие параметры (одинаковы для всех шаблонов)

| Параметр | Цель «масса» | Цель «сила» | Основание | Уверенность |
|---|---|---|---|---|
| Повторы, многосуставные | 6–10 | Главные движения 3–6 (присед, жим лёжа, тяга в наклоне, жим над головой), остальное как для массы | Мышцы растут при любом весе, если подход близок к отказу; сила лучше растёт с тяжёлыми весами (Lopez и соавт. 2021) | Умеренные данные |
| Повторы, изолирующие | 10–15 (махи и икры 12–20) | Как для массы | Удобно и безопаснее для суставов при лёгких весах | Мало данных |
| Запас повторов (RIR) | Многосуставные 1–3, изолирующие 0–2 | Главные движения 2–3 | Работа до отказа не даёт заметного преимущества для роста (Refalo 2023); 1–2 повтора в запасе дают тот же рост, что отказ (Refalo 2024) | Умеренные данные |
| Отдых между подходами | Многосуставные 2–3 мин, изолирующие 1–2 мин | Главные движения 3–5 мин | Отдых от 60 с, вероятно, немного лучше для роста (Singer 2024); для тяжёлых подходов нужно больше времени на восстановление | Умеренные данные / мнение экспертов |
| Порядок | Сначала многосуставные, потом изолирующие | То же | Самые тяжёлые упражнения — пока нет усталости | Консенсус |
| Длительность | 50–75 мин | 60–80 мин | Практичность | — |

**Недельный объём.** Ориентир — около 10–12 тяжёлых рабочих подходов на крупную мышцу в неделю для человека с опытом от года и 6–10 для новичка. Подход в многосуставном упражнении засчитывается вспомогательным мышцам как половина (например, жим лёжа = 0,5 подхода для трицепса). Чем больше объём, тем меньше прирост от каждого добавленного подхода; в одной тренировке эффект перестаёт расти примерно после 11 таких подходов на мышцу (Pelland и соавт., метарегрессия 67 исследований). Уверенность: **умеренные данные**; объём будет подстраиваться правилами прогрессии (блок 4).

**Опыт.** Для новичков (меньше года регулярных тренировок) приложение убирает по одному подходу в каждом основном упражнении.

**Калибровка RIR.** Первые 2 недели все подходы делаются с запасом 3 повтора: человек учится чувствовать «сколько ещё смог бы», а приложение — подбирать рабочие веса. Новички часто плохо оценивают свой запас повторов (уверенность: **мало данных**, это логика безопасности, а не результат исследований).

**Разминка (решение №17).** Перед тренировкой — подсказка общей разминки 5–7 мин (лёгкое кардио + суставы). Перед первым многосуставным упражнением дня — автоматические разминочные подходы: ~50% рабочего веса × 8, ~70% × 4, ~85% × 2 (для цели «сила» добавляется ~92% × 1). Числа — практика тренеров, а не результат исследований: **мало данных**. Перед следующими упражнениями на ту же группу мышц разминка не нужна; на новую группу — один подход ~60% × 6–8.

**Цель «сила» и частота.** Для силы частота тренировок движения важнее, чем для роста мышц (Pelland и соавт.). Поэтому при цели «сила» приложение рекомендует фулбади ×3 или верх/низ ×4, а при выборе классического сплита объясняет этот минус.

**Акцент на ягодицы.** Если пользователь его выбрал, в день ног добавляется хип-траст 3×8–12.

**Замены.** Любое упражнение можно заменить одной из альтернатив из списка упражнений; приложение предлагает их автоматически.

Обозначения: «3×6–10» — 3 рабочих подхода по 6–10 повторов. Квадратные скобки — вариант для цели «сила».

## 2. Фулбади ×2 (A и B)

Для загруженных недель. Каждая мышца 2 раза в неделю, ~6–8 подходов в неделю — меньше оптимума для роста, честно пишем об этом в описании. Пример расписания: понедельник и четверг.

| День A | Подходы × повторы | День B | Подходы × повторы |
|---|---|---|---|
| Гакк-присед [присед со штангой 3×3–6] | 3×6–10 | Жим ногами | 3×8–12 |
| Жим гантелей лёжа [жим штанги лёжа 3×3–6] | 3×6–10 | Отжимания на брусьях | 3×6–12 |
| Тяга верхнего блока | 3×8–12 | Тяга горизонтального блока [тяга штанги в наклоне 3×3–6] | 3×8–12 |
| Румынская тяга | 2×8–10 | Сгибание ног сидя | 3×10–15 |
| Махи гантелями в стороны | 2×12–20 | Жим гантелей сидя над головой | 2×8–12 |
| Разгибание рук из-за головы | 2×10–15 | Сгибание рук со штангой EZ | 2×8–12 |
| Подъём на носки стоя | 2×12–20 | Скручивания на блоке | 2×10–15 |

## 3. Фулбади ×3 (A, B, C)

Каждая мышца 2–3 раза в неделю, в каждой тренировке немного подходов на мышцу. Пример: понедельник, среда, пятница.

| День A | | День B | | День C | |
|---|---|---|---|---|---|
| Гакк-присед [присед 3×3–6] | 3×6–10 | Румынская тяга | 3×8–10 | Жим ногами или болгарские сплит-приседания | 3×8–12 |
| Жим гантелей лёжа [жим штанги 3×3–6] | 3×6–10 | Жим гантелей сидя над головой [жим штанги стоя 3×3–6] | 3×8–12 | Жим гантелей на наклонной | 3×8–12 |
| Тяга горизонтального блока [тяга в наклоне 3×3–6] | 3×8–12 | Тяга верхнего блока или подтягивания | 3×8–12 | Тяга гантели одной рукой | 3×8–12 |
| Махи в стороны | 3×12–20 | Отжимания на брусьях | 3×6–12 | Сведения в кроссовере | 2×12–15 |
| Сгибание ног сидя | 2×10–15 | Подъём на носки стоя | 3×12–20 | Разгибание ног | 2×12–15 |
| Сгибание рук EZ | 2×8–12 | Разгибание рук из-за головы | 2×10–15 | Обратные разведения | 2×12–20 |
| | | | | Скручивания на блоке | 2×10–15 |

Объём в неделю (прямые подходы): грудь ~11, спина ~9 (+ румынская тяга), квадрицепс ~8, бицепс бедра ~5 + румынская тяга, дельты ~5 изолирующих + жимы.

## 4. Классический сплит ×3 (ваша схема)

Каждая мышца 1 раз в неделю. Пример: понедельник, среда, пятница.

| День 1: грудь + бицепс | | День 2: спина + трицепс | | День 3: ноги + плечи | |
|---|---|---|---|---|---|
| Жим гантелей лёжа [жим штанги 3×3–6] | 3×6–10 | Тяга верхнего блока или подтягивания | 3×8–12 | Гакк-присед [присед 4×3–6] | 4×6–10 |
| Жим гантелей на наклонной | 3×8–12 | Тяга горизонтального блока [тяга в наклоне 3×3–6] | 3×8–12 | Румынская тяга | 3×8–10 |
| Отжимания на брусьях | 3×6–12 | Тяга гантели одной рукой | 2×8–12 | Сгибание ног сидя | 3×10–15 |
| Сведения в кроссовере | 2×12–15 | Пуловер на верхнем блоке | 2×12–15 | Подъём на носки стоя | 3×12–20 |
| Сгибание рук EZ | 3×8–12 | Разгибание рук из-за головы | 3×10–15 | Жим гантелей сидя над головой | 3×8–12 |
| Сгибание с гантелями на наклонной скамье | 2×10–15 | Разгибание рук на верхнем блоке | 2×10–15 | Махи в стороны | 3×12–20 |
| | | Скручивания на блоке | 2×10–15 | | |

Становая тяга по желанию (цель «сила») ставится первой в день 2: 3×3–5.

**Честные минусы этой схемы:**
- Грудь — 11 подходов за одну тренировку, это верхняя граница, после которой дополнительные подходы почти не добавляют роста.
- День 3 самый длинный (~75–85 мин): ноги и плечи вместе. При нехватке времени приложение предложит сократить румынскую тягу и махи до 2 подходов.
- Разгибания ног и задней дельты в этой схеме нет — иначе день 3 станет слишком длинным. Их можно добавить по желанию.
- Для цели «сила» частота ниже оптимальной (см. раздел 1).

## 5. Верх / низ ×4

Каждая мышца 2 раза в неделю. Пример: понедельник (верх A), вторник (низ A), четверг (верх B), пятница (низ B).

| Верх A | | Низ A | | Верх B | | Низ B | |
|---|---|---|---|---|---|---|---|
| Жим штанги лёжа [3×3–6] | 3×5–8 | Присед со штангой [3×3–6] | 3×5–8 | Жим гантелей на наклонной | 3×8–12 | Гакк-присед или жим ногами | 3×8–12 |
| Тяга штанги в наклоне или горизонтального блока | 3×6–10 | Румынская тяга | 3×8–10 | Отжимания на брусьях | 3×6–12 | Сгибание ног сидя | 3×10–15 |
| Жим гантелей сидя над головой | 2×8–12 | Разгибание ног | 2×12–15 | Тяга верхнего блока или подтягивания | 3×8–12 | Болгарские сплит-приседания | 2×8–12 |
| Тяга верхнего блока | 2×8–12 | Подъём на носки стоя | 3×12–20 | Тяга гантели одной рукой | 2×10–12 | Подъём на носки сидя | 3×12–15 |
| Сгибание рук EZ | 2×8–12 | Скручивания на блоке | 2×10–15 | Махи в стороны | 3×12–20 | Подъём ног в упоре или висе | 2×10–15 |
| Разгибание рук из-за головы | 2×10–15 | | | Сведения в кроссовере | 2×12–15 | | |
| | | | | Обратные разведения | 2×12–20 | | |

Становая по желанию (цель «сила») заменяет румынскую тягу в низе A: 3×3–5.

## 6. Чего в шаблонах нет (и почему)

- **Плановой разгрузочной недели.** Когда снижать нагрузку, решают правила прогрессии и самочувствия (блоки 4 и 5), а не календарь.
- **Предплечий и кардио по умолчанию.** Они добавляются по желанию (решения №18, №19).
- **Суперсетов и других техник интенсивности.** Для MVP лишнее.
