# Этап 1: дорожная карта MVP

Дата: 2026-10-27. Связанные решения: №9–№12 в [DECISIONS.md](../DECISIONS.md).

## Цель MVP (версия 0.1)

Один работающий цикл для самоучки в зале: **открыл → понял, что делать сегодня → быстро записал → приложение само подсказало, что делать в следующий раз и почему.** Только Android, без сервера, все данные на телефоне.

## Что входит в 0.1

| Функция | Зачем |
|---|---|
| Каталог упражнений (~40–60 базовых): короткое описание техники, работающие мышцы, частые ошибки | Основа программ; знания «в контексте» |
| Онбординг: цель (масса / сила), опыт, дней в неделю, доступное оборудование | Выбор шаблона программы |
| Скрининг-анкета по образцу PAR-Q+ | Безопасность: при «красных флагах» программа не выдаётся, показывается совет обратиться к врачу |
| 4 шаблона программ: фулбади ×2, фулбади ×3, классический сплит ×3, верх/низ ×4 (решение №16) | Готовый план без самостоятельной сборки; выбор по числу дней и предпочтению |
| Разминка: подсказка общей разминки 5–7 мин + автоматические разминочные подходы (решение №17) | Лучшая подготовка к тяжёлым подходам |
| Экран тренировки с быстрой записью: прошлые значения подставлены, RIR, таймер отдыха | Главный экран; от его удобства зависит всё |
| Двойная прогрессия: диапазон повторов → прибавка веса | «Что делать в следующий раз» без догадок |
| Отметка самочувствия перед тренировкой (сон, энергия, боль в мышцах, болезнь) → корректировка нагрузки | Наше главное отличие от конкурентов |
| Кнопка «почему?» у каждой рекомендации | Понимание вместо «по ощущениям» |
| История и график по каждому упражнению | Видимый прогресс |
| Экспорт и импорт данных в файл | Защита от потери данных при смене телефона |

## Отбор упражнений (выполняется на Этапе 2)

«Самого лучшего упражнения» не существует: лучшее зависит от цели, оборудования, анатомии и травм человека. Поэтому упражнения отбираются по явным критериям, а не по популярности.

**Критерии:**

1. **Полное покрытие.** Все основные мышечные группы и двигательные паттерны: присед, тазовый шарнир (становая и её варианты), выпады, горизонтальные и вертикальные жимы и тяги, плюс изоляция для рук, дельт, икр и мышц кора.
2. **Эффективность для гипертрофии и силы по исследованиям.** Например, есть данные, что упражнения с нагрузкой в растянутом положении мышцы дают больший рост (сгибание ног сидя против лёжа, разгибание рук из-за головы против разгибания на блоке). Уверенность: **умеренные данные**.
3. **Безопасность и простота освоения для самоучки.** Предпочтение движениям с низкой технической сложностью и стабильной нагрузкой; сложные варианты (например, рывковые движения) не включаются.
4. **Доступность в типичном зале РФ**: свободные веса, стандартные тренажёры, блоки.
5. **Удобство прогрессии**: можно добавлять вес маленькими шагами.
6. **Замены.** У каждого упражнения 2–3 альтернативы (тренажёр занят, нет оборудования, дискомфорт в суставе).

**Чем не руководствуемся:** рейтингами упражнений по ЭМГ (электрической активности мышц). Высокая активность на ЭМГ ненадёжно предсказывает рост мышц. Уверенность: **умеренные данные**.

**Процесс:**

1. Длинный список кандидатов.
2. Оценка каждого по критериям выше, с источниками и уровнем уверенности.
3. Короткий список ~40–60 упражнений с заменами — **на утверждение основателю**.
4. Только после утверждения пишутся карточки: работающие мышцы, техника, частые ошибки, меры безопасности, источники.

## Требования к экрану записи (из отзывов о конкурентах)

Основатель сам не стал вести записи даже в готовых приложениях. Значит, запись должна требовать почти ноль усилий:

1. Повторить прошлый подход — **одно касание**.
2. Ввод веса и повторов кнопками «+/–» и колесом, без клавиатуры.
3. После записи подхода фокус сам переходит дальше, таймер отдыха запускается сам (в Hevy жалуются, что нет кнопки «Далее»).
4. Если упражнение заменили посреди тренировки, приложение предлагает сохранить замену в программу (на отсутствие этого тоже жалуются в Hevy).
5. Тренировку можно записать неполностью: ничего не теряется.
6. На экране тренировки нет питания, рекламы и предложений купить. Разработчики конкурентов сообщают, что пользователи закрывают приложение, когда их просят записать ещё и еду.
7. Никаких «наказывающих» серий дней (красные цифры, сброс счётчика). Вместо них — недельная цель.

Уверенность в пунктах 6–7: **мало данных**, это наблюдения разработчиков, а не исследования. Отдельно: данные Fitbod показывают, что за 5–8 недель до того, как человек бросает, он начинает пропускать тренировки. Значит, пропуски нужно встречать мягко.

## Этапы разработки 0.1

Каждый этап заканчивается работающим APK, который можно установить на телефон. Каждый этап согласуется до начала.

| № | Этап | Результат |
|---|---|---|
| M0 | Каркас проекта | Репозиторий на GitHub, автосборка APK, пустое приложение запускается на Honor |
| M1 | Каталог упражнений | Список и карточки упражнений (контент — Этап 2) |
| M2 | Тренировка и запись | Можно провести и записать свободную тренировку; история |
| M3 | Онбординг, скрининг, шаблоны | Анкета → безопасная проверка → готовая программа |
| M4 | Прогрессия | Приложение предлагает вес и повторы на следующую тренировку; автотесты правил |
| M5 | Самочувствие и «почему?» | Корректировка нагрузки по самочувствию с объяснением |
| M6 | Графики, экспорт, полировка | Версия 0.1 готова к 4-недельной проверке на себе |

Грубая оценка: 3–4 месяца при текущем темпе. Уверенность низкая.

## Критерии «0.1 готова»

1. Основатель 4 недели подряд записывает все тренировки в Apexi.
2. Подход, повторяющий прошлый, записывается в 1–2 касания.
3. Правила прогрессии и корректировки по самочувствию покрыты автотестами.
4. Работает без интернета и без тормозов на Honor основателя.
5. При «красных флагах» в анкете программа не выдаётся.
6. За 4 недели ни одной потери данных.
