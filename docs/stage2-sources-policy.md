# Этап 2, блок 1: правила работы с источниками

Дата: 2026-10-28. Применяются ко всему контенту Apexi: карточкам упражнений, программам, правилам прогрессии, текстам «почему?», расчётам питания.

## 1. Иерархия источников (от сильных к слабым)

| Уровень | Тип | Примеры |
|---|---|---|
| 1 | Позиции и рекомендации профессиональных организаций | ACSM, NSCA, ISSN, ВОЗ |
| 2 | Систематические обзоры и метаанализы | Schoenfeld и соавт. о частоте и объёме; Lauersen и соавт. о профилактике травм |
| 3 | Отдельные рандомизированные исследования | Например, исследования Maeo и соавт. о тренировке в растянутом положении |
| 4 | Механистические и наблюдательные данные | ЭМГ, биомеханические модели, острые реакции |
| 5 | Мнение экспертов, практический опыт | Учебники, тренеры с публичной репутацией |

Не принимаются: блоги и сайты производителей без ссылок на исследования, обзоры приложений-конкурентов, видео блогеров без источников, тексты, сгенерированные ИИ без проверки по первоисточнику.

## 2. Уровни уверенности (показываются в тексте «почему?»)

| Метка | Когда ставится |
|---|---|
| **Консенсус** | Позиция профессиональных организаций и/или несколько согласующихся метаанализов |
| **Умеренные данные** | Один метаанализ или несколько согласующихся рандомизированных исследований |
| **Спорно / мало данных** | Отдельные исследования, противоречивые результаты, только механистические данные |
| **Не знаю** | Данных нет; так и пишем, без выдуманных цифр |

## 3. Правила

1. **Каждое ключевое утверждение имеет источник и метку уверенности.** Без источника утверждение в приложение не попадает.
2. **Цифры только из первоисточника или его аннотации.** Если цифру удалось найти только во вторичном источнике, это помечается, и цифра не используется как точная.
3. **Ограничения исследований называются явно:** участники-новички или опытные, длительность, малые выборки. Многие исследования проведены на нетренированных молодых мужчинах; переносить их результаты на всех нужно осторожно.
4. **Популярные мифы не повторяем**, а объясняем, что показывают данные (пример: растяжка как профилактика травм).
5. **ЭМГ-рейтинги упражнений не считаются доказательством эффективности для роста мышц.**
6. **Медицинских советов не даём.** При симптомах (боль, отёк, нестабильность сустава, ограничение подвижности, симптомы со стороны сердца) — совет обратиться к врачу.
7. **Тексты для пользователя короче научных:** вывод простыми словами, метка уверенности, ссылка на источник для желающих.

## 4. Процесс проверки

1. Claude собирает данные и пишет черновик с источниками и метками.
2. Основатель утверждает или правит.
3. Перед выходом к посторонним пользователям контент проверяет сертифицированный тренер или спортивный врач (открытый вопрос в журнале решений).
4. Раз в год источники пересматриваются: появляются новые метаанализы.
